An entry for [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) on make.fun: one sentence, at most 200 characters, explaining the modern internet to a time traveler from the year 1800, built only from things they already know — a road, a library, a post office, a letter, a book.

## How it works

`main.py` writes a single line to `/output/entry.txt`. The program is fully
deterministic — it produces byte-identical output on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
